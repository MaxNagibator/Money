# Кадры Филочки (Money)

Снято на веб-клиенте Vue 1.3.17 ([рабочая версия](https://money.keep2space.ru), [обзор в README](../../README.md), [руководство](../../GUIDE.md)) с демонстрационными данными.
Основной размер настольных кадров: 1440 × 900 (действия с долгами: 1440 × 1060, статистика: 1440 × 1169, полная страница настроек: 1440 × 1960); мобильные экраны сняты в портретном окне смартфона (390 × 844).

| Сцена | Кадр |
| --- | --- |
| Операции: карточки дней, суммы с выровненными копейками и итоги периода (тёмная тема) | [operations-dark.png](operations-dark.png) |
| Та же сцена списка операций в светлой теме | [operations-light.png](operations-light.png) |
| Диалог операции: вычисленная сумма по формуле и чип автоподстановки категории по месту | [operation-dialog-dark.png](operation-dialog-dark.png) |
| Фильтр операций: выбор периода, дерево категорий и пакетный перенос выборки | [operations-filter-dark.png](operations-filter-dark.png) |
| Статистика: столбчатая динамика, круговая диаграмма долей и дерево сумм категорий | [statistics-dark.png](statistics-dark.png) |
| Категории: иерархическое дерево расходов с цветами и порядком сортировки | [categories-dark.png](categories-dark.png) |
| Быстрые операции: карточки шаблонов для создания записи в один клик | [fast-operations-dark.png](fast-operations-dark.png) |
| Регулярные операции: карточки расписаний и диалог настройки ежемесячного шага | [regular-operations-dark.png](regular-operations-dark.png) |
| Долги: секции «Нужно забрать» и «Нужно отдать», группы держателей и прогресс погашения | [debts-dark.png](debts-dark.png) |
| Долги: окна частичного погашения и прощения безнадёжных долгов в расходы | [debts-actions-dark.png](debts-actions-dark.png) |
| Авто: вкладки автомобилей, журнал событий и подсказка последнего пробега | [cars-dark.png](cars-dark.png) |
| Настройки: выбор темы, расписание тёмной темы, выравнивание копеек и статус PWA | [settings-dark.png](settings-dark.png) |
| Личный кабинет: статус подтверждения почты и смена пароля | [profile-dark.png](profile-dark.png) |
| Мобильная оболочка: список операций и нижняя панель навигации с кнопкой «+» | [mobile-operations-dark.png](mobile-operations-dark.png) |
| Мобильная шторка: форма ввода операции поверх списка на узком экране | [mobile-sheet-dark.png](mobile-sheet-dark.png) |

[Две темы в одном окне](../readme/themes.png): светлая и тёмная.

Все данные в кадрах демонстрационные и не содержат личных сведений реальных пользователей.
